## 🎨 Design System

- **Theme:** Rose Pink (`#ec4899`)
- **Default Mode:** Light
- **Dark Mode:** Supported (toggle + localStorage persistence)
- **Typography:** Tajawal (Arabic) + Inter (Latin)
- **Icons:** Boxicons

## ✨ Features

- Responsive design (4 breakpoints: 1200px, 992px, 768px, 480px)
- Dark/Light theme toggle with persistence
- Typing + flip text animation in hero
- Animated stats counter
- Project filter tabs
- Contact form with validation (Formspree ready)
- Copy-to-clipboard for contact info
- Scroll reveal animations
- Glassmorphism navbar
- Verified badge with hover tooltip
- Bilingual support (Arabic RTL + English LTR)

## 🚀 Setup

1. Add your profile image as `assets/images/yotamo.jpg`
2. Add project images in `assets/images/`
3. Update social media links in `index.html` and `en/index.html`
4. Update the Formspree form ID in both contact forms
5. Update the CNAME file with your actual domain
6. Deploy to GitHub Pages
